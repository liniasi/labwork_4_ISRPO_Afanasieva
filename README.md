### Основные понятия unittest:

- Тестовый случай (test case) — один отдельный тест. Он проверяет, что функция даёт правильный ответ на конкретные входные данные.
- Тестовый набор (test suite) — группа тестов, которые запускаются вместе.
- Тестовый раннер (test runner) — программа, которая запускает тесты и показывает результат.
- Тестовый матч (test fixture) — то, что нужно подготовить перед тестом (например, данные), и убрать после него.

Идея автоматических тестов простая: мы вызываем функцию, получаем от неё ответ и сравниваем с тем, который ожидаем. Если ответы совпадают, тест проходит (OK). Если нет, unittest показывает, в каком месте ответы разошлись.

### Тестируется программа rectangle.py. В ней две функции:

`area(a, b)` считает площадь прямоугольника (a · b);
`perimeter(a, b)` считает периметр прямоугольника (2 · (a + b)).

На вход функции получают длины сторон, на выходе возвращают число.

### Область тестирования

Тестируются только две функции: area и perimeter. Ввод и вывод данных, интерфейс и всё остальное не проверяются.

### Стратегия тестирования

Используется модульное (unit) тестирование через библиотеку unittest.

Сначала я вручную считаю, какой ответ должен получиться. Потом пишу тесты, которые сравнивают ответ функции с ожидаемым. `Проверяются разные случаи`:

- обычные числа;
- квадрат (стороны равны);
- ноль (граничный случай);
- дробные числа.

Для дробных чисел использовалась проверка assertAlmostEqual, потому что в Python дробные числа считаются с маленькой погрешностью (например, 0.1 * 3 даёт 0.30000000000000004, а не 0.3).

### Тестовые данные

| № |	Функция|	Вход	|Ожидаемый ответ|	Что проверяем|
|---|----------|------------|---------------|----------------|
| 1 |	area	|  (10, 0)	|0	            |            ноль|
| 2 |	area	|  (10, 10)	|100            |	      квадрат|
| 3	|   area	|(3, 5)	    |15         	|обычный  прямоугольник|
| 4	| perimeter	|(3, 5)	    |16	            |обычный прямоугольник|
| 5	|   area	|(0.1, 3)	|0.3            |	дробные числа|

Код тестов


``` python
import unittest
from rectangle import area, perimeter

class RectangleTestCase(unittest.TestCase):

    def test_zero_area(self):
        self.assertEqual(area(10, 0), 0)

    def test_square_area(self):
        self.assertEqual(area(10, 10), 100)

    def test_rect_area(self):
        self.assertEqual(area(3, 5), 15)

    def test_perimeter(self):
        self.assertEqual(perimeter(3, 5), 16)

    def test_float_area(self):
        self.assertAlmostEqual(area(0.1, 3), 0.3)

if __name__ == "__main__":
    unittest.main()
```
### Запуск тестов:
```
python -m unittest test_rectangle.py
```
